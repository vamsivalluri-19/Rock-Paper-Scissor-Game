# 🎮 Rock Paper Scissors Game

A modern and animated **Rock Paper Scissors Game** built using **HTML, CSS, and JavaScript** with futuristic UI effects and interactive gameplay.

---

# 🚀 Live Features

✅ Animated Gaming UI  
✅ Glassmorphism Design  
✅ Video-Style Background Animations  
✅ Floating Particles & Neon Effects  
✅ Score Tracking System  
✅ Computer AI Moves  
✅ Winning Streak Counter  
✅ Round Counter  
✅ Reset Game Button  
✅ Game History Panel  
✅ Responsive Design  
✅ Hover & Glow Effects  

---

# 📸 Preview

## Main Gameplay

- Choose Rock, Paper, or Scissors
- Computer randomly selects a move
- Winner is calculated instantly
- Scores update dynamically

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
